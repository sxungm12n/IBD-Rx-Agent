- 내용: "2024 보험가이드북 기준만 쓰고, 진단·용량 제안·논문·병원 관행은 덧붙이지 않는다" + 답 형식.

### 기본 AI를 RAG와 같은 틀로 (2026-11-23, `llm-same`)
기존 기본 AI 지시문은 RAG 지시문과 세 군데가 달랐다: 지어내기 금지 문장(진단·용량 제안·논문·병원 관행 ↔ 수치·조건·금기), 지시를 사용자 메시지에 한 번 더 넣음, 사용자 메시지 모양('문제:' ↔ '질문: / 가이드북 발췌:'). 그래서 기존 비교는 엄밀히 'RAG + 지시문 차이'의 효과다.

새 조건 `llm-same`(`eval_claude_batch.no_rag_prompt`)은 RAG 지시문을 그대로 가져와 아래 두 줄만 바꾸고, 사용자 메시지도 같은 모양에 발췌 칸만 '없음'으로 둔다. 바뀌는 것은 발췌가 있느냐뿐이다.

| | RAG 에이전트 | llm-same |
|---|---|---|
| 둘째 줄 | 근거는 제공된 발췌뿐입니다. 발췌에 없는 수치, 조건, 금기는 만들지 않습니다. | 가이드북 발췌는 주어지지 않습니다. 알고 있는 가이드북 기준으로 답하며, 가이드북에 없는 수치, 조건, 금기는 만들지 않습니다. |
| 기준 없을 때 (A·A2형) | - 발췌에 그 기준이 없으면 … | - 가이드북에 그 기준이 없으면 … |
| 사용자 메시지 '가이드북 발췌:' 칸 | 상위 5쪽 | 없음 |
| 나머지 | 글자까지 같음 | 글자까지 같음 |

- 실행: `eval_csvrag_batch.py build --arm llm-same --tag llm_same_full` → 결과 `eval_out/{,a2_,c_,d_}llm-same_gpt-5.6-terra/`.
- 보고: 기존 기본 AI와 llm-same을 함께 내서, 지시문 차이가 결론에 주는 영향을 보인다. RAG 효과는 llm-same 대비로 말한다.

**해결 (2026-11-23):** 맞춤 선생은 편향이 커서 더 쓰지 않고, 일반 선생 지시문(해시 `60e30c0dc140`)으로 바꿨다. 맞춤 지시문은 `_archive/teacher_tailored_601b7ce19375.md`에 보관하고, 11-20 파일럿 결과(`self_pilot`·`opus_pilot`)는 '맞춤 선생'으로만 보고한다.

일반 선생에서 바꾼 것
- 점검 항목: 근거 없음 / 잘못 옮김 / 질문과 다른 대상 / 발췌에 없는 덧붙임 / 빠진 내용 / 형식 (RAG 답 검토의 일반 항목). 약·경로·체크리스트·'반응 없음·내약성 없음·금기'·이미 실패한 약 같은 구체 힌트는 모두 뺐다.
- 쪽 종류: 가이드북 목차의 장·쪽 이름만 쓴다. '(검사 하한·금기 확인 항목)', '처방 기간', 예시 약 이름을 뺐다.
- 새 규칙: "학생 답이 발췌에 근거하고 질문에 모두 답했다면 통과. 발췌에서 가리킬 수 있는 문제가 없으면 고치게 하지 않는다." 맞은 답을 2회차에 흔든 사례(A2-ADA-GIBD-L)를 보고 넣었다. 특정 문항 내용이 아니라 검토 원칙이지만, 파일럿을 보고 넣었다는 점은 적는다.
- 남은 것: `찾기`의 약·질환·경로 칸과 쪽 종류 목록은 쪽 찾기 도구의 입력 형식(가이드북 메타데이터)이다.
- 폴더·실행 이름에 `-g`를 붙인다 (`self-g_pilot`, `loop-opus-g_pilot_…`).

참고: route 조건의 규칙 B(고시 쪽에 체크리스트·투약간격 쪽을 붙임)도 `simulate_retrieval.py`의 오답 분석에서 나왔다. 선생 지시문은 아니지만 같은 성격의 한계로 적는다.

## 5. 채점자 v2.1 🟡

### 데이터셋 맞춤
- v2.1 규칙은 **2026-10-27 첫 답을 받은 뒤, 2026-11-10에 v1·v2·v2.1 채점을 비교해 확정**했다(`_archive/README.md`, `regrade_v21_compare.txt`). 즉 답을 본 뒤 채점 규칙을 정했다.
  - '평가 시점만 틀리면 부분'
  - '결과를 밝힌 여집합 표현(N 미만이면 투여 불가)은 맞음'
  - '함께 써도 정답은 있든 없든 감점 없음'
- 채점자는 어느 조건의 답인지 모르고(눈가림), 규칙은 모든 조건에 똑같이 적용된다. 그래서 특정 조건만 유리하게 만들지는 않는다. 다만 **어떤 답 스타일이 유리한지**는 달라질 수 있다.
  - 예: '원문에 없는 덧붙임은 틀림'은 발췌 없이 지어내는 기본 AI에 더 불리하다. 이 규칙의 영향은 `sensitivity_additions.py`(덧붙임 규칙을 좁게·넓게 끈 민감도)로 이미 보고 있다.
- 동의어 목록(스테로이드=코르티코스테로이드, 6-MP 등)과 '이전 치료 필수 요소 3개'는 채점 열쇠 구조에서 나온 것이라 답에 맞춘 것은 아니다. 🟢

### 공정성 · 한계
- **채점자 독립성:** 채점자(gpt-6-sol)와 학생(gpt-5.6-terra)이 같은 회사 모델이라, 자기 계열 답을 좋게 볼 수 있다. 연구 방침상 채점자는 gpt-6-sol 하나만 쓰고, 이 점은 한계로 적는다.
- **원문 발췌:** 채점자는 문항의 `source_page` 쪽을 원문으로 받는다. 모든 조건에 같은 쪽이 가므로 공정하다.
- **반복 채점:** A형 74문항 3회 반복에서 판정 일치도가 높았다(에이전트 74/74, 기본 AI 71/74). 루프·CSV-RAG 답은 아직 1회 채점이다.
- **사람 검증 미실시 (가장 큰 빈칸):** `make_judge_check.py`(임상의 눈가림 채점 → κ)를 아직 돌리지 않았다. 채점자 규칙이 답을 본 뒤 정해진 만큼, 사람–채점자 일치도로 정당성을 보여 줘야 한다.
