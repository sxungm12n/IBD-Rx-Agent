# 오류 분석 정리 · 세 모델 × 두 대상 (2026-11-16, API 없음)

- 숫자 출처: `error_analysis_models.py` → `오답원인_모델별.md`·`.json` (코드 규칙, 다시 돌리면 같은 값).
- 해석과 사례 읽기는 Claude가 했다. 사람(임상의) 검수 전이다.
- 세 모델 에이전트는 모두 gpt-5.6-terra가 검색한 같은 5쪽을 받았다. 그래서 '검색: 근거 쪽 없음'은 세 모델에 같은 조건이다.
- 규칙 확인: gpt 에이전트 A형 오답 28건을 손 분류(오답원인분류_에이전트.md)와 대조하면 27건이 같다. 다른 1건(A-IFX-IV-UC-adult-G4)은 근거 쪽도 없고 조건도 축약된 답이다. 코드는 검색을 먼저 보므로 '검색'으로 셌다.

## 1. 한 장 요약

| | gpt-5.6-terra | Claude Opus 5.5 | Qwen3-14B |
|---|---|---|---|
| 기본 AI가 틀리는 방식 | 그럴듯하게 지어냄(덧붙임 A 27), 외국·예전 기준(TNF 10) | 그럴듯하게 지어냄(덧붙임 A 34), 세부 수치·결합 오기억 | 모른다고 함(A 83/93이 '적혀 있지 않다'), 약 이름 표기 오류 |
| 에이전트 A형 잃은 점수 (101점 중) | 19.5 | 9.0 | 37.0 |
| 그중 검색(쪽 없음) | 6.0 | 7.0 | 6.5 |
| 그중 답변·읽기 | 13.5 (축약 7.5, 다른 기준 5) | 2.0 | 30.5 (다른 기준 13, 축약 9.5, 덧붙임 4) |
| 에이전트 C형 오답 | 13 (허용 6) | 5 (미룸 4) | 17 (허용 12) |
| 에이전트 D형 빠뜨린 약 (검색 / 읽기) | 43 / 0 | 21 / 0 | 46 / 8 (+이름 표기 3) |

- **모델이 좋을수록 남은 오답은 검색 문제다.** Opus 에이전트는 A형에서 잃은 9점 중 7점, A2형은 2.5점 전부, C형은 오답 5개 전부가 검색에서 생겼다.
- **모델이 약할수록 답변·읽기 오류가 커진다.** Qwen은 쪽이 있어도 다른 기준을 옮기고, 조건을 줄이고, 필수 요소를 빠뜨렸다.

## 2. 세 모델이 모두 틀린 문항 = 검색 구조 문제

세 에이전트가 같은 문항을 모두 틀렸고, 그 원인이 모두 '근거 쪽 없음'이다.

| 유형 | 문항 | 빠진 쪽 |
|---|---|---|
| A 7 | Filgotinib Hb·ALC, Upadacitinib UC Hb 하한 | 체크리스트 p.49·52 |
| | Infliximab IV UC 성인·소아·장형 베체트 유지, IV UC 이전 치료 | IV 고시 p.36·37 (SC 쪽 p.39 대신 옴) |
| A2 4 | Adalimumab 처방 기간 4문항 | 투약간격 p.28 (다른 약 장기처방 쪽 대신 옴) |
| C 5 | Filgotinib ANC·ALC, Upadacitinib Hb·ANC·ALC 미달 환자 | 체크리스트 p.49·52 |
| D 14 | 빠뜨린 약(Ozanimod·Vedolizumab 등) + Upadacitinib 안전 오답 6 | 약별 고시 쪽, 체크리스트 p.52 |

- C형 5문항에서 gpt와 Qwen은 모두 '예'(허용)로 답했다. Opus는 4문항을 '판단 불가'로 미뤘다. 같은 쪽 누락이라도 상위 모델은 더 조심스럽게 실패한다.
- D형 Upadacitinib 안전 오답 6건은 세 모델 모두 체크리스트 p.52 없이 넣었다.

## 3. 모델별로 다른 오류

### gpt-5.6-terra
- 에이전트: 조건 축약 15(A형 이전 치료 '내약성 없음·금기' 생략), 다른 기준 옮김 5(누공·베체트 함정에서 유지 기준을 답함), 유지 결과가 없는 C형 사례를 '아니오'로 단정 3, 이미 실패한 약 재사용 4(D).
- 기본 AI: TNF 기준 혼동 10(A), 급여 대상을 막음 23(C, 그중 이유에 TNF·생물학제제 11), 해외 약 Risankizumab 3(D).

### Claude Opus 5.5
- 에이전트: 답변 단계 오류가 거의 없다. 축약 0, 재사용 0. A형 2건은 '소아 평가 시점은 적혀 있지 않다'를 덧붙여 원문과 모순이 생긴 경우다. D형은 쪽이 없는 약을 기억으로 채웠지만(49), 새 경구약(Ozanimod·Filgotinib·Tofacitinib)은 못 채웠다.
- 기본 AI: TNF 혼동은 0이다. 대신 덧붙임 34(A), 유지 '또는'→'그리고', 소아·베체트 기준 오기억, 68세 JAK 허용(C 4)이 있었다.

### Qwen3-14B
- 기본 AI
  - **모른다고 답함:** A 83, A2 35. 지어낸 덧붙임은 A 6.
  - **C형 오답이 70개로 가장 많다.**
    - 활성도 경계값(CDAI 219, Mayo 5, PUCAI 45)을 허용 14
    - 점수가 없는 사례를 '예'로 단정 9
    - 유지 인정 사례를 막음 12
    - 이전 치료 기준 문항에서 허용 8
    - 정리하면 '숫자 경계와 정보 없음'을 다루지 못한다.
  - **D형 약 이름:**
    - 알아보지 못한 이름 32개 중 27개는 가이드북 약의 잘못된 한글 표기다(아다리무맙·벡도리주맙·투파시티닙 등).
    - 4개는 가이드북에 없는 해외 약이다(세르토리주맙 페골 = Certolizumab 3, 세쿠키누맙 = Secukinumab 1).
    - gpt·Opus가 Risankizumab을 쓴 것처럼 Qwen도 국내 급여가 아닌 약을 썼다. 다만 채점 코드가 이름을 못 알아봐서 '해외 약'으로 잡히지 않았다.
- 에이전트
  - **다른 기준 옮김 13:** 활성도를 물었는데 같은 쪽의 '지속 투여' 기준(Mayo 30% 감소, DAIBD 20점 감소, 누공 50% 감소)을 답했다.
  - **조건 축약 17:** '금기' 또는 '내약성 없음'을 빠뜨렸다.
  - **A2 필수 요소 빠뜨림 13:** 퇴원 시 2주분 4, 투약 일지 관리 주체(요양기관) 3, 증량의 '반응 감소 시' 조건 2 등.
  - **쪽이 있는데 '적혀 있지 않다' 3:** JAK의 고령·고위험 조항.
  - **C형 허용 12**
    - 검사 하한 5
    - 이전 치료 부족 5: '2가지 이상' 조건을 무시하고 한 가지 실패로 허용했다. 소아 UC는 이전 치료가 필요 없다고 읽은 경우도 있다.
    - 유지 1: PCDAI 5점 감소를 '12.5점 이상'으로 계산했다.
    - 고령·고위험 1: 68세에게 생물학제제 실패 없이 Upadacitinib 허용
  - **D형 쪽이 있는데 빠뜨림 8:** Golimumab 5 등. 이름 표기 오류로 빠진 것으로 잡힌 3건은 따로 셌다.

## 4. 약 이름 표기를 인정하면 (참고, 채점 코드는 그대로)

| D형 완전 일치 | 지금 규칙 | 표기 변형 인정 (NAME_VARIANTS 표) |
|---|---|---|
| Qwen 기본 AI | 1 / 37 | 1 / 37 |
| Qwen 에이전트 | 10 / 37 | 11 / 37 |
| gpt · Opus | 변화 없음 (알아보지 못한 이름 0) | |

- 표기 변형을 인정해도 Qwen D형 점수는 거의 그대로다(에이전트 0.27 → 0.30). 이름 외의 오류(약을 빠뜨림, 잘못 넣음)가 함께 있기 때문이다.
- 그래서 채점 규칙은 지금처럼 엄격하게 두고, 표기 변형을 인정한 값은 참고로 함께 보고하는 것을 제안한다.
- 대응표(`error_analysis_models.py`의 `NAME_VARIANTS`)는 Claude가 읽고 정한 것이며 사람 검수 전이다.

## 5. 정확도를 올리려면 (원인별, 사후 분석으로 보고)

| 순서 | 방법 | 겨냥하는 오답 | 효과가 클 모델 | API |
|---|---|---|---|---|
| 1 | 체크리스트·투약간격 쪽 자동 첨부 (규칙 A) | 세 모델 공통 A 3·C 5·D 안전 6, A2 4 | 모두 (특히 안전 오답) | 답 다시 받기만 |
| 2 | 질문의 약·제형으로 고시 쪽 붙이기 (규칙 B), D형은 약별 검색 | IV/SC 혼동 4, D 빠뜨림 21~46 | 모두. Opus는 A형 잃은 9점 중 7점이 여기 | 같음 |
| 3 | 답 지시문: '조건 문장을 빠짐없이 옮겨라', '시작 기준과 지속 기준을 구분하라' | 축약 15~17, 다른 기준 5~13 | gpt·Qwen | 같음 |
| 4 | D형 규칙 기반: AI는 환자 사실만 뽑고 판정은 코드 | D형 전체, 실패 약 재사용, 계산 오류 | 모두 | 적음 |
| 5 | 약 이름은 영문 성분명으로 쓰게 하기 | Qwen 이름 오류 | Qwen | 같음 |
| 6 | 근거를 못 찾으면 '판단 불가' | 허용 쪽 안전 오답 | gpt·Qwen | 같음 |

- 1·2번만으로 A형에서 최대 +0.06~0.07(세 모델 모두)을 기대할 수 있다. 쪽이 들어온 뒤 실제로 맞히는지는 답을 다시 받아야 안다.
- 이 오답을 보고 만든 개선이므로, 결과는 사후 분석으로 보고하거나 새 사례로 검증한다(과적합 주의).
